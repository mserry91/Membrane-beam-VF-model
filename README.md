This folder contains the MATLAB code used to simulate the membrane--beam vocal fold model presented in the paper *"A Membrane--Beam Biomechanical Vocal Fold Model Incorporating Geometric Effects"*.

A sample simulation can be run using the script `example.m`, where the user may specify the desired muscle activation levels and subglottal pressure.

To ensure proper execution, make sure that all folders and subfolders are present and accessible within the project directory.
